# Оболочка FFmpeg: руководство

## Конвертация
1. Перетащите видео или аудио в верхнюю область (или **Добавить файлы**).
2. Справа выберите **Шаблон**: сжатие, Telegram, Reels, YouTube, WhatsApp, формат, звук, GIF, обрезка, разрешение, поворот, без звука, кадры.
3. При необходимости измените качество, высоту, формат и другие параметры. В таблице виден примерный размер каждого файла.
4. Поля **Начало / Конец** необязательны: `90`, `1:30` или `00:01:30.5`.
5. Нажмите **Начать**. Для каждого файла показывается процент, **Отмена** останавливает работу.
6. Результат сохраняется рядом с исходным файлом (или в выбранной папке) с именем вида `имя_compressed.mp4`. Существующие файлы не перезаписываются.

Если выделено несколько строк, обрабатываются только они.

## Кодировщик
Режим **Авто** выбирает самый быстрый H.264 кодировщик (NVIDIA NVENC, AMD AMF, Intel QSV, Windows Media Foundation или OpenH264). Если аппаратный кодировщик выдаст ошибку, программа повторит работу с OpenH264.

## Расширенная команда
Выберите файл в очереди и нажмите **Команда (расширенно)**. Команду ffmpeg можно посмотреть, скопировать или изменить и применить к этому файлу.

## Объединение
Добавьте файлы и задайте порядок кнопками **Выше / Ниже**. Если файлы одного формата, режим **Быстро** склеивает их без перекодирования.

## Сведения о медиа
Перетащите файл: длительность, разрешение, кодеки, битрейт и все потоки.
